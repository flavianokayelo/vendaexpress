# Standard

## Objetivo

Tema universal e estavel para lojas de e-commerce que precisam de uma experiencia familiar, simples e confiavel.

## Ideal para

- Loja geral
- Pequenos negocios
- Catalogos mistos
- Primeira versao de uma loja

## Direcao visual

- Layout claro, direto e previsivel.
- Header com busca, categorias e acesso rapido ao carrinho.
- Hero equilibrado, sem linguagem visual muito marcada.
- Produtos em grade com boa leitura de preco, imagem e acao.
- Cores neutras com acento forte para chamadas principais.

## Home

Ordem recomendada:

1. Announcement bar
2. Hero
3. Banners promocionais
4. Perfil da loja
5. Navegacao por tabs
6. Categorias
7. Promocoes
8. Novidades
9. Catalogo completo

## Componentes

- `Header`: completo, com busca e categorias.
- `ProductCard`: equilibrado, com imagem quadrada.
- `ProductGrid`: funciona bem em grid e rail.
- `Cart`: drawer lateral padrao.
- `Footer`: completo, com links e suporte.

## Notas

Este tema deve ser o fallback visual da engine. Evitar experimentos fortes aqui.
